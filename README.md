# portfolio
Welcome! This repository showcases a selection of projects I've completed to demonstrate my skills in data science and analytics. Each project includes a brief description, tools used, and links to relevant code and documentation.

Hurricane_Property_Prices_DiD - Code for a study investigating the impact of Hurricane Sandy on housing prices in Atlantic County,
New Jersey, using a Difference-in-Differences (DiD) approach. Hurricane Sandy, which struck the northeastern U.S. in October 2012, caused significant damage to homes, particularly in New Jersey, leading to a sharp decline in tourism and local economic activity. Atlantic County, designated as a flood zone, faced substantial insurance recovery costs and long-term property value disruptions. This study uses housing price data from Atlantic County and Sussex County, which served as a control group due to its relatively low exposure to the hurricane’s effects. The analysis spans eight quarters before and eight quarters after the event to capture both immediate and long-term effects. By comparing pre- and post-disaster price trends in the treatment (higher intensity) and control counties (lower intensity), the study tests the hypothesis that Hurricane Sandy increases housing prices in Atlantic County, reflecting limited supply and the inherent valuable location characteristics that would hold post-disaster. The findings of this research offer valuable insights for policymakers, real estate developers, and homeowners, providing a better understanding of how natural disasters influence housing markets and economic resilience. This study was a major group project for the course Econometrics, part of the Master's in Applied Economics and Applied Analytics at Boston College. The project was created using R.

DiabetesData - Code for a study predicting cases of type 2 diabetes using machine learning methods. Diabetes is a chronic disease that affects millions of Americans. Approximately 11.6% of the U.S population has diabetes and 22.8% of adults with diabetes are undiagnosed. Machine learning enhances healthcare efficiency and patient outcomes by enabling early diabetes detection from clinical and lifestyle factors. A diabetes dataset was analyzed using ML methods, including logistic regression, K-Nearest Neighbors (KNN), and Support Vector Machines (SVM). Training and validation data optimized model parameters, while test data evaluated final performance. Naive Bayes outperformed other models in predicting prediabetes and diabetes, based on F1 score and Recall. This study adds to the literature on using ML for disease prediction, with further analysis incorporating additional variables as a potential next step. This study was a co-led project as part of a presentation for the Boston College Analytics Industry Symposium for 2025. The project was created using Python.
